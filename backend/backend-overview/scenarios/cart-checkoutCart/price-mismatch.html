cart-checkoutCart · Price Mismatch

Server-side recalculation detects that the client's expectedTotal no longer matches the authoritative price, so the checkout aborts with a descriptive error.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table001",
    "sessionId": "session_abc123",
    "expectedTotal": 252
  }
}

Sample Error Response

{
  "status": "error",
  "message": "Price mismatch detected",
  "error": {
    "code": "price-mismatch",
    "httpCode": 412,
    "details": {
      "expected": 252,
      "actual": 258,
      "items": ["item001"]
    }
  }
}
