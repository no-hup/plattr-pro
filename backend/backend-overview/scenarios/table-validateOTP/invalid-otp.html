table-validateOTP · Invalid or Expired OTP

The provided OTP is expired. The callable throws unauthenticated with contextual metadata so the client can prompt the guest again.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table001",
    "otp": "000000",
    "phoneNumber": "+911234567890"
  }
}

Sample Error Response

{
  "status": "error",
  "message": "OTP expired",
  "error": {
    "code": "invalid-otp",
    "httpCode": 401,
    "details": {
      "otpExpiresAt": "2024-01-01T10:05:00Z"
    }
  }
}
