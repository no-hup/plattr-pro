table-validateOTP · Secondary Customer

Multi-user support is enabled, so the callable appends a new guest to the existing session without creating a new one.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table001",
    "otp": "193746",
    "name": "Jane Smith",
    "sessionId": "session_abc123"
  }
}

Sample Response

{
  "status": "success",
  "message": "Secondary guest added",
  "data": {
    "session": {
      "sessionId": "session_abc123",
      "users": [
        {
          "customerId": "cust001",
          "username": "John Doe",
          "isPrimary": true
        },
        {
          "customerId": "cust002",
          "username": "Jane Smith",
          "isPrimary": false
        }
      ]
    },
    "table": {
      "tableId": "table001",
      "status": "ACTIVE"
    }
  }
}
