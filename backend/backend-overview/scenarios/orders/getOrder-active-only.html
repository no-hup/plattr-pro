order-getOrder

Scenario: Fetch only the active orders for the table.

Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table009",
    "activeOnly": true
  }
}

Response

{
  "status": "success",
  "message": "Orders retrieved",
  "data": {
    "orders": [
      {
        "orderId": "order_20251114_001",
        "orderNumber": "ORD-458",
        "orderStatus": "active",
        "carts": [ ... ],
        "priceInfo": {
          "finalPrice": 1160,
          "paymentStatus": "pending"
        }
      }
    ]
  }
}

Notes

  • Used by both the consumer order-tracking screen and the server dashboard.
  • Combines cart status updates with order-level history.
