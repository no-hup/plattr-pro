order-getOrder

Scenario: Return all orders placed by the session, including completed ones.

Request

{
  "data": {
    "restaurantId": "rest001",
    "sessionId": "sess_table009_primary",
    "getAllOrders": true,
    "activeOnly": false
  }
}

Response

{
  "status": "success",
  "message": "Orders retrieved",
  "data": {
    "orders": [
      {
        "orderId": "order_20251114_001",
        "orderStatus": "completed",
        "statusHistory": [ ... ],
        "priceInfo": { "finalPrice": 1160, "paymentStatus": "paid" }
      },
      {
        "orderId": "order_20251114_002",
        "orderStatus": "active",
        "statusHistory": [ ... ],
        "priceInfo": { "finalPrice": 312, "paymentStatus": "pending" }
      }
    ]
  }
}

Notes

  • Client uses this to populate the order timeline component.
  • Includes sanitized cart items (no sensitive server notes).
