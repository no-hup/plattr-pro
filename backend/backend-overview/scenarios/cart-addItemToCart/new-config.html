cart-addItemToCart · New Configuration

Adds a burger with a unique combination of variant/addon choices, so a new cart item is created.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table001",
    "menuItemId": "item001",
    "quantity": 1,
    "selectedVariants": {
      "variant_burger_size": "burger_size_large"
    },
    "selectedAddons": ["addon_burger_fries"],
    "sessionId": "session_abc123"
  }
}
