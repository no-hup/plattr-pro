cart-addItemToCart · New Item

Scenario: Customer adds a brand-new configuration to the cart.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table009",
    "menuItemId": "item_classic_burger",
    "quantity": 1,
    "selectedVariants": { "variant_size": "large" },
    "selectedAddons": ["addon_fries"],
    "sessionId": "sess_table009_primary"
  }
}
