cart-fetchCart · Empty Cart

Scenario: Table cart exists but contains zero items after cleanup.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table010"
  }
}

Sample Response

{
  "status": "success",
  "message": "Cart retrieved successfully.",
  "data": {
    "cart": {
      "restaurantId": "rest001",
      "tableId": "table010",
      "items": [],
      "priceInfo": {
        "basePrice": 0,
        "finalPrice": 0,
        "totalDiscount": 0,
        "totalDiscountAmount": 0,
        "totalAddonBasePrice": 0,
        "totalVariantBasePrice": 0
      },
      "lastUpdated": "2025-11-14T09:00:00Z"
    }
  }
}

Notes

  • Ensures the frontend never receives null carts.
  • Cart document stays around for auditability until TTL clears it.
