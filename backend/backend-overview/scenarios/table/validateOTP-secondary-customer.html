table-validateOTP

Scenario: Multi-user flag enabled; secondary user joins the active session.

Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table009",
    "otp": "789012",
    "phoneNumber": "+919876543210",
    "name": "Ravi",
    "userLocation": { "latitude": 12.9717, "longitude": 77.5945 }
  }
}

Response

{
  "status": "success",
  "message": "Joined existing session",
  "data": {
    "sessionId": "sess_table009_primary",
    "addedUser": {
      "customerId": "cust_ravi",
      "isPrimary": false
    },
    "tableState": "ACTIVE"
  }
}

Notes

  • Requires isMultiUserSupportEnabled=true.
  • Session document appends the new user to users array.
