# unassignTableSample.md

## Success Response
```json
{
  "success": true,
  "message": "Table unassigned successfully.",
  "data": {
    "tableId": "<table_id>"
  }
}
```

## Error Response
```json
{
  "success": false,
  "message": "Failed to unassign table.",
  "errorCode": "TABLE_UNASSIGN_ERROR"
}
```
