# updateServerSample.md

## Success Response
```json
{
  "success": true,
  "message": "Server updated successfully.",
  "data": {
    "serverId": "<server_id>"
  }
}
```

## Error Response
```json
{
  "success": false,
  "message": "Failed to update server.",
  "errorCode": "SERVER_UPDATE_ERROR"
}
```
