🆔 Table & OTP APIs

Consumer-facing APIs for table authentication, OTP validation, and session creation.

▶ validateTableAndLocation PUBLIC Validate table access via QR scan and location
Request Parameters
{ "restaurantId": "string", // Required - from QR code "tableId": "string", // Required - from QR code "userLocation": { // Required - user GPS coordinates "latitude": 37.7749, "longitude": -122.4194 }, "sessionId": "string" // Optional - for existing session validation }
Success Response (with valid session)
{ "status": "success", "message": "Access granted", "data": { "status": "success", "tableStatus": "active", // 'active' | 'vacant' | 'pending' "restaurant": { "name": "Baseline Bistro", "id": "rest_basic_001" }, "table": { "number": "B1", "id": "table1", "capacity": 4, // Nullable "assignedServerId": "server_bob" // Only if assigned }, "session": { "sessionId": "sess_b1_001", "expiresAt": "2024-01-15T14:30:00.000Z" }, "primaryCustomer": { // Only for active tables "phoneNumber": "1234567890", "name": "John Customer" }, "occupiedBy": ["1234567890"] // Array of phone numbers } }
OTP Required Response (HTTP 401 - when isOtpManadatoryAtScan = true)
{ "tableStatus": "pending", // 'pending' for VACANT tables after OTP gen "restaurant": { "name": "Baseline Bistro", "id": "rest_basic_001" }, "table": { "number": "B2", "id": "table2" }, "primaryCustomer": null, // null for vacant tables "assignedServer": { // If server is assigned "id": "server_anna", "name": "Anna Waiter" }, "authMessage": "Please ask the server for the table OTP", "isUsernameMandatory": true, // Based on isUsernameEnabled flag "isPhoneNumberMandatory": true, // Always true for VACANT/OTP_PENDING "isMultiUserSupported": true, // Based on isMultiUserSupportEnabled flag "otpRequired": true, "error": "OTP authentication required" }
Success Response (when isOtpManadatoryAtScan = false)
{ "status": "success", "message": "Access granted", "data": { "tableStatus": "vacant", "restaurant": { ... }, "table": { ... }, "otpRequiredForOrder": true // For ACTIVE tables only } }
Error Response (403 - Table Disabled)
{ "code": "permission-denied", "message": "This table is currently unavailable", "details": { "tableStatus": "disabled", "error": "Table is disabled" } }
Error Response (412 - Location Check Failed)
{ "code": "failed-precondition", "message": "User not in restaurant premises", "details": { "error": "User location validation failed" } }
⚠️ HTTP 403 if table is DISABLED. HTTP 412 if location check fails (currently stubbed to always pass).
▶ validateOTP PUBLIC Validate OTP and create/join session
Request Parameters
{ "restaurantId": "string", // Required "tableId": "string", // Required "otp": "string", // Required - 6-digit OTP from server "phoneNumber": "string", // Required for primary OR when multi-user disabled "name": "string" // Conditional - required when isUsernameEnabled AND primary }
Success Response (Primary Customer)
{ "status": "success", "message": "OTP validated successfully", "data": { "token": "eyJhbGciOiJSUzI1NiIsInR5cCI6...", // Firebase custom token "tableId": "table1", "tableNumber": "B1", "tableStatus": "active", "session": { "id": "sess_b1_001", "primaryUserId": "1234567890", "users": ["1234567890"], "status": "active", "expiresAt": "2024-01-15T14:30:00.000Z" }, "customer": { "phoneNumber": "1234567890", "name": "John Customer", "isPrimary": true }, "restaurant": { "id": "rest_basic_001", "name": "Baseline Bistro" } } }
Success Response (Secondary Customer - joining existing session)
{ "status": "success", "message": "OTP validated successfully", "data": { "token": "eyJhbGciOiJSUzI1NiIsInR5cCI6...", "tableId": "table1", "tableNumber": "B1", "tableStatus": "active", "session": { "id": "sess_b1_001", "primaryUserId": "1234567890", // Original primary "users": ["1234567890", "9876543210"], // Now includes secondary "status": "active", "expiresAt": "2024-01-15T14:30:00.000Z" }, "customer": { "phoneNumber": "9876543210", "name": "Jane Diner", "isPrimary": false // Secondary customer }, "restaurant": { ... } } }
Error Response (401 - Invalid OTP)
{ "code": "unauthenticated", "message": "Invalid OTP", "details": { "details": "The provided OTP is incorrect", "tableStatus": "pending" } }
Error Response (401 - Wrong OTP for Active Table)
{ "code": "unauthenticated", "message": "Invalid OTP", "details": { "status": "ask_primary_customer", "message": "Please ask the primary customer or the server/waiter for the correct OTP.", "tableStatus": "active" } }
Error Response (400 - Missing Phone Number)
{ "code": "invalid-argument", "message": "Phone number is required for this operation", "details": { "details": "Phone number is required for primary customers or when multi-user support is disabled" } }
Primary customer: First to validate on VACANT/OTP_PENDING table. Secondary: Joins ACTIVE table with existing session.
⚠️ HTTP 401 if OTP is invalid or expired. Name required when isUsernameEnabled flag is ON and user is primary.
▶ checkTableStatus PUBLIC Get table status and details for consumer app
Request Parameters
{ "restaurantId": "string", // Required "tableId": "string" // Required }
Success Response

{ "code": "invalid-argument", "message": "Invalid or missing parameters" }
▶ cleanupInactiveSessions SCHEDULED Clean up stale sessions and reset inactive tables
Trigger
// Scheduled function - runs automatically // Can also be triggered manually via HTTP for testing Schedule: Every 30 minutes (configurable)
Behavior
  • Finds tables with lastActivity > 1 hour ago
  • Ends associated sessions (sets status to ended)
  • Resets table status to vacant
  • Clears primaryCustomer, occupiedBy, activeOrderId
⚠️ TODO: Should check for cart/order activity in last 2 hours, not just general activity.
🖥️ Server App APIs

APIs for waiters/staff to manage tables, view details, and generate OTPs.

▶ generateTableOTP SERVER-APP Generate new OTP for a table
Request Parameters
{ "restaurantId": "string", // Required "tableId": "string" // Required }
Success Response
{ "status": "success", "message": "Table OTP generated successfully", "data": { "tableId": "table1", "tableNumber": "B1", "otp": "123456", // 6-digit code "otpGeneratedAt": "2024-01-15T10:30:00.000Z", "otpExpiresAt": "2024-01-15T10:35:00.000Z" // 5 min from generation } }
Error Response (404 - Not Found)
{ "code": "not-found", "message": "Table not found", "details": { "restaurantId": "rest_basic_001", "tableId": "invalid_table" } }
OTP is valid for 5 minutes. Can be regenerated at any time by server staff.
▶ updateTableStatus SERVER-APP Update table status (clear table, disable, etc.)
Request Parameters
{ "restaurantId": "string", // Required "tableId": "string", // Required "status": "string" // Required - 'active' | 'vacant' | 'disabled' | 'pending' }
Success Response
{ "status": "success", "message": "Table status updated successfully", "data": { "tableId": "table1", "tableNumber": "B1", "previousStatus": "active", "currentStatus": "vacant", "changed": true // false if already in requested status } }
When changing ACTIVE → VACANT, system automatically clears primaryCustomer, occupiedBy, and activeOrderId.

Error Response (404 - Restaurant Not Found)
{ "code": "not-found", "message": "Restaurant not found", "details": { "details": "Restaurant with ID rest_invalid was not found", "restaurantId": "rest_invalid" } }
Error Response (400 - Missing Parameters)
{ "code": "invalid-argument", "message": "Missing required parameter: restaurantId", "details": { "details": "restaurantId is required" } }

⏱️ Session APIs (Internal)

Internal service functions for session management. Not directly callable via HTTP.

▶ createOrGetTableSession INTERNAL Create new or retrieve existing session for a table
Function Signature
createOrGetTableSession( restaurantId: string, tableId: string, primaryUserId: string // Phone number of primary customer ) => Promise<Session>
Return Value
{ "id": "sess_b1_001", "tableId": "table1", "primaryUserId": "1234567890", "users": ["1234567890"], "status": "active", "createdAt": Timestamp, "updatedAt": Timestamp, "expiresAt": Date // 4 hours from creation }
Error Response (404 - Restaurant Not Found)
{ "code": "not-found", "message": "Restaurant not found" }
Error Response (500 - Failed to Create Session)
{ "code": "internal", "message": "Failed to create table session: [error details]" }
If active session exists for table, adds user to it instead of creating new one.
▶ addUserToTableSession INTERNAL Add user to existing session
Function Signature
addUserToTableSession( restaurantId: string, sessionId: string, userId: string // Phone number of user to add ) => Promise<Session>
Return Value
{ "id": "sess_b1_001", "tableId": "table1", "primaryUserId": "1234567890", "users": ["1234567890", "9876543210"], "status": "active", ... }
Error Response (404 - Session Not Found)
{ "code": "not-found", "message": "Session not found" }
Error Response (412 - Session Expired)
{ "code": "failed-precondition", "message": "Session has expired" }
⚠️ Throws failed-precondition if session is expired. Auto-marks session as EXPIRED.
▶ validateTableSession INTERNAL Validate session for a table
Function Signature
validateTableSession( restaurantId: string, tableId: string, options: { context: FirebaseContext, // For user management throwError: boolean // Default: false } ) => Promise<Session | null>
Return Value
// Returns session object if valid, null if not (when throwError=false) { "id": "sess_b1_001", "tableId": "table1", "primaryUserId": "1234567890", "users": ["1234567890"], "status": "active", "expiresAt": Timestamp }
Error Response (401 - Unauthenticated)
{ "code": "unauthenticated", "message": "User must be authenticated" }
Error Response (412 - No Active Session)
{ "code": "failed-precondition", "message": "No active session found" }
Auto-expires session if past expiresAt. Can optionally add authenticated user to session.
▶ endTableSessions INTERNAL End active session for a table
Function Signature
endTableSessions( restaurantId: string, tableId: string ) => Promise<void>
Behavior
  • Finds active session for the table
  • Sets session status to ended
  • Updates updatedAt timestamp
  • Silently returns if no active session found
👤 Customer APIs

APIs for customer profile management and visit tracking.

▶ createOrUpdateCustomerProfile PUBLIC Create or update customer profile
Request Parameters
{ "phoneNumber": "string", // Required - used as document ID "name": "string" // Optional - only updates if provided }
Success Response
{ "id": "1234567890", "phoneNumber": "1234567890", "name": "John Customer", "createdAt": Timestamp, "updatedAt": Timestamp, "visits": [] }
Error Response (400 - Missing Phone Number)
{ "code": "invalid-argument", "message": "Phone number is required" }
Error Response (500 - Internal Error)
{ "code": "internal", "message": "Failed to create/update customer profile: [error details]" }
Phone number serves as document ID. Called internally by validateOTP via createOrUpdateCustomerProfileDirect.
▶ getOrCreateCustomerProfile PUBLIC Get customer profile (requires authentication)
Request Parameters
// No explicit parameters - uses context.auth.uid (phone number) {}
Success Response
{ "phoneNumber": "1234567890", "name": "John Customer", "email": "john@example.com", "createdAt": Timestamp, "updatedAt": Timestamp, "currentVisit": { "restaurantId": "rest_basic_001", "tableId": "table1", "startTime": Timestamp }, "visits": [ { "restaurantId": "rest_basic_001", "tableId": "table1", "startTime": Timestamp, "endTime": Timestamp // null if visit ongoing } ], "preferences": { "favoriteItems": [], "dietaryRestrictions": [] } }
Error Response (401 - Unauthenticated)
{ "code": "unauthenticated", "message": "User must be logged in" }
Error Response (404 - Profile Not Found)
{ "code": "not-found", "message": "Customer profile not found" }
⚠️ Requires Firebase authentication. Returns not-found if profile doesn't exist.
▶ updateCustomerVisit PUBLIC Record new visit for authenticated customer
Request Parameters
{ "restaurantId": "string", // Required "tableId": "string" // Required }
Success Response
{ "message": "Customer visit updated successfully" }
Error Response (401 - Unauthenticated)
{ "code": "unauthenticated", "message": "User must be logged in" }
Error Response (404 - Profile Not Found)
{ "code": "not-found", "message": "Customer profile not found" }
Adds visit to visits[] array and sets currentVisit. Requires authentication.
▶ endCustomerVisit PUBLIC End current visit and update table status
Request Parameters
// No explicit parameters - uses context.auth.uid {}
Success Response
{ "message": "Customer visit ended successfully" }
Behavior
  • Adds endTime to the current visit
  • Clears currentVisit field
  • Updates table status to vacant
  • Clears table occupiedBy
Error Response (401 - Unauthenticated)
{ "code": "unauthenticated", "message": "User must be logged in" }
Error Response (412 - No Active Visit)
{ "code": "failed-precondition", "message": "No active visit found" }
⚠️ Returns failed-precondition if no active visit found.
▶ createOrUpdateCustomerProfileDirect INTERNAL Direct customer profile update (used by validateOTP)
Function Signature
createOrUpdateCustomerProfileDirect( phoneNumber: string, name: string ) => Promise<CustomerProfile>
Return Value
{ "id": "1234567890", "phoneNumber": "1234567890", "name": "John Customer", "createdAt": Timestamp, "updatedAt": Timestamp, "visits": [] }
Same as createOrUpdateCustomerProfile but callable directly (not via HTTP). Used internally by validateOTP.
🚫 Error Handling
HTTP Status Codes
Status Code Scenario
400 Bad Request Missing parameters, invalid request format
401 Unauthorized OTP required, invalid OTP provided
403 Forbidden Table is disabled
404 Not Found Restaurant/table/session not found
412 Precondition Failed User not in restaurant premises, session expired
500 Internal Error Server errors, database failures
