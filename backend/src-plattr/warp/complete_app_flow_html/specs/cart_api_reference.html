Request Parameters
{ "tableId": "table1", // Required "restaurantId": "rest_basic_001", // Required "menuItemId": "item_burger_cls", // Required (fallback identifier) "cartItemId": 1 // Optional but preferred (precise identifier) }
Sample Response (Quantity Decremented)
{ "status": "success", "message": "Item removed from cart successfully.", "data": { "cart": { "restaurantId": "rest_basic_001", "tableId": "table1", "items": [ // Updated items array { "cartItemId": 1, "menuItemId": "item_burger_cls", "quantity": 1, // Decremented from 2 "priceInfo": { ... } // Recalculated } ], "priceInfo": { "basePrice": 140, "finalPrice": 126, "totalDiscount": 10, "totalDiscountAmount": 14 }, "lastUpdated": "2024-01-15T10:35:00.000Z" } } }
Error Response (404 - Cart Not Found)
{ "code": "not-found", "message": "Cart not found for the table." }
Error Response (404 - Item Not Found)
{ "code": "not-found", "message": "Item not found in cart." }
📝 If cart becomes empty, the entire cart document is deleted and returns empty items: [] with zeroed priceInfo.
📝 cartItemId takes precedence over menuItemId for precise item matching (disambiguates same menu item with different customizations).
▶ checkoutCart PUBLIC Convert cart to order and clear cart
Request Parameters
{ "restaurantId": "rest_basic_001", // Required "tableId": "table1", // Required "sessionId": "sess_b1_001", // Required (MANDATORY!) "notes": "No onions please" // Optional - special instructions }
Sample Response (Success)
{ "status": "success", "message": "Checkout completed successfully.", "data": { "orderId": "order_b1_001", // Firestore document ID "orderNumber": "ORD-00001", // Human-readable order number "orderStatus": "IN_PROGRESS", // New orders start IN_PROGRESS "timestamp": "2024-01-15T10:30:00.000Z" } }
Error Response (401 - Session Required)
{ "code": "unauthenticated", "message": "OTP validation required for checkout", "details": { "requiresOTP": true, "tableId": "table1" } }
Error Response (412 - Out of Stock)
{ "code": "failed-precondition", "message": "Cannot checkout. The following items are out of stock: Classic Burger" }
⚠️ Session is MANDATORY. No sessionId returns 401 with OTP requirements.
📝 Cart is cleared after successful checkout. If cart clearing fails after order creation, order is still considered successful.
📝 If active order exists for same table+session, cart is appended to existing order (multi-cart support).

Function Signature
clearCartInternal( restaurantId: string, tableId: string ) => Promise

▶ updateCartStatus PUBLIC Update status of cart within an order (kitchen workflow)
Request Parameters
{ "restaurantId": "rest_basic_001", // Required "orderId": "order_b1_001", // Required "cartIndex": 0, // Required - 0-based index in order.carts[] "newStatus": "ACCEPTED", // Required - valid CART_STATUS "notes": "Kitchen acknowledged", // Optional - status change notes "sessionId": "sess_b1_001" // Optional - validated if provided }
Valid newStatus Values
PENDING ACCEPTED PREPARING READY SERVED RETURNED CANCELLED
Sample Response (Success)
{ "success": true, "message": "Cart status updated to ACCEPTED", "data": { "id": "order_b1_001", "restaurantId": "rest_basic_001", "tableId": "table1", "orderStatus": "IN_PROGRESS", "carts": [ { "status": "ACCEPTED", "statusHistory": [ { "status": "PENDING", "timestamp": "2024-01-15T10:30:00.000Z", "userId": "system" }, { "status": "ACCEPTED", "timestamp": "2024-01-15T10:32:00.000Z", "userId": "server_bob", "notes": "Kitchen acknowledged" } ], "assignedTo": "server_bob", // Set when ACCEPTED "items": [ ... ] } ], "updatedAt": "2024-01-15T10:32:00.000Z" } }
Error Response (400 - Invalid Status Transition)
{ "code": "internal", "message": "Invalid status transition from PENDING to READY" }
Error Response (404 - Order/Cart Not Found)
{ "code": "internal", "message": "Cart at index 0 not found in order order_b1_001" }
Error Response (412 - Invalid Session)
{ "code": "failed-precondition", "message": "Invalid or inactive session" }
📝 When status becomes ACCEPTED, assignedTo is set to the userId making the change.
📝 Every status change appends to statusHistory[] with timestamp and userId.
