📖 Menu Fetch APIs
▶ getRestaurantMenu PUBLIC Primary menu fetch API – default inStock=false (returns ALL items)
Request Parameters
{ "restaurantId": "rest_basic_001", // Required - Restaurant document ID "inStock": false // Optional, default: false (returns ALL items) }
Sample Response (Success)
{ "status": "success", "message": "Restaurant menu fetched successfully", "data": { "categories": [ { "id": "cat_food", "name": "Food", "order": 1, "description": "All-time favourites", "image": "https://example.com/images/cat-food.jpg" }, { "id": "cat_bev", "name": "Beverages", "order": 2, "description": "Drinks", "image": "https://example.com/images/cat-bev.jpg" } ], "menuItems": { "cat_food": [ { "menuItemId": "item_burger_cls", "categoryId": "cat_food", "meta": { "name": "Classic Burger", "description": "Beef patty with cheddar", "categoryName": "Food", "image": "https://example.com/images/burger-classic.jpg" }, "priceInfo": { "basePrice": 100, "discount": 10, // Percentage (0-100) "finalPrice": 90 // basePrice * (1 - discount/100) }, "variants": [ // Enriched from variants collection { "id": "var_size_burger", "name": "Size", // Contextual name from MenuItem ref "meta": { "name": "Burger Size", "description": "Choose size", "categoryAssociatedWith": ["cat_food"] }, "options": [ { "id": "size_reg", "name": "Regular", "priceInfo": { "basePrice": 0, "finalPrice": 0, "discount": 0 } }, { "id": "size_lg", "name": "Large", "priceInfo": { "basePrice": 20, "finalPrice": 18, "discount": 10 } } ], "isMandatory": true, // Customer MUST select before add-to-cart "respectParentDiscount": true // Inherits parent item discount } ], "addons": [ // Enriched from addons collection { "id": "addon_fries", "name": "French Fries", "priceInfo": { "basePrice": 20, "discount": 0, "finalPrice": 20 }, "respectParentDiscount": true, "isInStock": true } ], "nutritionalInfo": { "calories": 600, "protein": 30, "carbs": 40, "fat": 30 }, "allergenTags": ["gluten", "dairy"], "isInStock": true, "isCustomizable": true // Auto-computed: has variants OR addons } ], "cat_bev": [ { "menuItemId": "item_tea", "categoryId": "cat_bev", "meta": { "name": "House Tea", "description": "Simple and warm", "categoryName": "Beverages", "image": "https://example.com/images/tea.jpg" }, "priceInfo": { "basePrice": 20, "discount": 0, "finalPrice": 20 }, "variants": [], "addons": [], "isInStock": true, "isCustomizable": false } ] }, "metadata": { "totalCategories": 2, "totalMenuItems": 2 } } }
Error Response (400 - Missing Restaurant ID)
{ "status": "error", "message": "Restaurant ID is required", "data": { "code": "invalid-argument", "httpCode": 400 } }
Error Response (404 - Restaurant Not Found)
{ "status": "error", "message": "Restaurant not found", "data": { "code": "not-found", "httpCode": 404, "restaurantId": "invalid_rest_id" } }
Default inStock=false returns ALL items regardless of stock status. Pass inStock=true to filter to only available items.
Input Format Handling

Supports both data.data.restaurantId (standard callable format) and data.restaurantId (direct object format).

▶ fetchMenu PUBLIC Secondary fetch API – default inStock=true (returns ONLY in-stock items)
Request Parameters
{ "restaurantId": "rest_basic_001", // Required - Restaurant document ID "inStock": true // Optional, default: true (filters to in-stock only) }
Sample Response (Success)
// Same structure as getRestaurantMenu, but only includes: // - Menu items where isInStock === true // - Addons where isInStock === true // - Variants are NOT filtered (always included) { "status": "success", "message": "Restaurant menu fetched successfully", "data": { "categories": [...], "menuItems": { ... }, // Only in-stock items "metadata": { ... } } }
Error Response (400 - Invalid Request Format)
{ "status": "error", "message": "Invalid request data", "data": { "code": "invalid-argument", "httpCode": 400 } }
Error Response (400 - Missing Restaurant ID)
{ "status": "error", "message": "Restaurant ID is required", "data": { "code": "invalid-argument", "httpCode": 400 } }
Uses MenuValidation.validateMenuFetchInput() – stricter validation requiring data.data.restaurantId format. Default inStock=true (INVERTED from getRestaurantMenu).
✏️ Menu Item CRUD APIs
▶ addMenuItem PUBLIC Create a new menu item with auto-computed fields
Request Parameters
{ "restaurantId": "rest_basic_001", "menuItemData": { "meta": { "name": "Veggie Wrap", // Required "description": "Fresh vegetables in a wrap", "categoryName": "Food", "image": "https://example.com/wrap.jpg" }, "categoryId": "cat_food", // Required - Must exist in categories "priceInfo": { "basePrice": 85, // Required - number "discount": 0, // Optional - percentage (0-100) "finalPrice": 85 // Optional - auto-calculated if not provided }, "variants": [ // Optional - array of variant references { "id": "var_size_burger", // Reference to variants collection "name": "Size" // Contextual display name } ], "addons": ["addon_fries"], // Optional - array of addon IDs "nutritionalInfo": { "calories": 350, "protein": 12, "carbs": 45, "fat": 10 }, "allergenTags": ["gluten"], "isInStock": true // Optional - Default: true } }
Sample Response (Success)
{ "status": "success", "message": "Menu item added successfully", "data": { "menuItemId": "AbC123XyZ456", // Firestore auto-generated ID "menuItem": { "id": "AbC123XyZ456", "meta": { "name": "Veggie Wrap", ... }, "categoryId": "cat_food", "priceInfo": { ... }, "variants": [...], "addons": [...], "isInStock": true, "isCustomizable": true, // Auto-computed "lastUpdated": { "_seconds": 1678901234, ... } } } }
Error Response (400 - Missing Required Fields)
{ "status": "error", "message": "Restaurant ID and menu item data are required", "data": { "code": "invalid-argument", "httpCode": 400, "hasRestaurantId": false } }
Error Response (400 - Invalid Menu Item Data)
{ "status": "error", "message": "Menu item data is missing required fields", "data": { "code": "invalid-argument", "httpCode": 400, "restaurantId": "rest_basic_001" } }
Auto-Computed Fields
  • isCustomizable: Set to true if variants OR addons are provided
  • lastUpdated: Set to server timestamp
  • isInStock: Defaults to true if not provided
▶ updateMenuItem PUBLIC Update menu item with isCustomizable recomputation
Request Parameters
{ "restaurantId": "rest_basic_001", "menuItemId": "item_burger_cls", "updateData": { // All fields optional - only include what to update "meta": { "name": "Updated Burger", // Required IF meta is provided "description": "New description", "categoryName": "Food", "image": "https://example.com/new.jpg" }, "categoryId": "cat_food", "priceInfo": { "basePrice": 120, // Required IF priceInfo is provided (must be number) "discount": 15, "finalPrice": 102 }, "variants": [...], // Replace entire variants array "addons": [...], // Replace entire addons array "nutritionalInfo": { ... }, "allergenTags": [...], "isInStock": false } }
Sample Response (Success)
{ "status": "success", "message": "Menu item updated successfully", "data": { "menuItemId": "item_burger_cls", "menuItem": { // Full updated menu item object... "isCustomizable": true, // Recomputed based on new variants/addons "lastUpdated": { "_seconds": 1678902345, ... } } } }
Error Response (400 - Missing Required Fields)
{ "status": "error", "message": "Restaurant ID, menu item ID and update data are required", "data": { "code": "invalid-argument", "httpCode": 400, "hasRestaurantId": true, "hasMenuItemId": false } }
Error Response (404 - Menu Item Not Found)
{ "status": "error", "message": "Menu item not found", "data": { "code": "not-found", "httpCode": 404, "restaurantId": "rest_basic_001", "menuItemId": "nonexistent_id" } }
Error Response (400 - Invalid Update Data)
{ "status": "error", "message": "Base price must be a number if priceInfo is provided", "data": { "code": "invalid-argument", "httpCode": 400 } }
isCustomizable is RECOMPUTED on every update. If you remove all variants/addons, it will become false.
▶ deleteMenuItem PUBLIC Delete a menu item – NO cascade delete
Request Parameters
{ "restaurantId": "rest_basic_001", "menuItemId": "item_burger_cls" }
Sample Response (Success)
{ "status": "success", "message": "Menu item deleted successfully", "data": { "menuItemId": "item_burger_cls" } }
Error Response (400 - Missing Required Fields)
{ "status": "error", "message": "Restaurant ID and menu item ID are required", "data": { "code": "invalid-argument", "httpCode": 400, "hasRestaurantId": true } }
Error Response (404 - Menu Item Not Found)
{ "status": "error", "message": "Menu item not found", "data": { "code": "not-found", "httpCode": 404, "restaurantId": "rest_basic_001", "menuItemId": "nonexistent_id" } }
NO cascade delete – orphaned variant/addon references may remain. Variants and addons that were associated with this item are NOT deleted.
📦 Stock Management APIs
▶ updateMenuItemAvailability HTTP POST Toggle isInStock flag – Quick stock toggle endpoint
Request Parameters (HTTP POST Body)
{ "restaurantId": "rest_basic_001", "menuItemId": "item_burger_cls", "isAvailable": false // MUST be explicit boolean (not truthy/falsy) }
Sample Response (Success - HTTP 200)
{ "status": "success", "message": "Menu item availability updated successfully", "data": { "menuItemId": "item_burger_cls", "isAvailable": false, "menuItem": { "id": "item_burger_cls", "meta": { ... }, "isInStock": false, // Updated value "lastUpdated": { ... } // Updated timestamp } } }
Error Response (HTTP 400 - Invalid Request)
{ "status": "error", "code": "invalid_argument", "message": "Restaurant ID, menu item ID, and availability status (boolean) are required", "data": { "restaurantId": "rest_basic_001", "menuItemId": "item_burger_cls" } }
Error Response (HTTP 404 - Menu Item Not Found)
{ "status": "error", "code": "not_found", "message": "Menu item not found", "data": { "restaurantId": "rest_basic_001", "menuItemId": "nonexistent_id" } }
isAvailable MUST be an explicit boolean value (true or false). Truthy/falsy values like "true", 1, "" will be rejected.

Function Signature
getAllMenuItems(restaurantId: string): Promise<MenuItem[]> // Returns array of all menu items // Each item includes: { id, menuItemId, categoryId, meta, priceInfo, ... }
Throws (invalid-argument)
// Thrown when restaurantId is missing or empty throw new functions.https.HttpsError( 'invalid-argument', 'Restaurant ID is required' );
Used internally by menu fetch operations. Validates restaurantId via MenuValidation.validateRestaurantId().
▶ getMenuItemById INTERNAL Fetch single menu item by ID
Function Signature
getMenuItemById( restaurantId: string, menuItemId: string ): Promise<MenuItem> // Throws Error('Menu item not found') if document doesn't exist
Throws (Error)
// Thrown when menu item document doesn't exist throw new Error('Menu item not found'); // Also validates via MenuValidation: throw new functions.https.HttpsError( 'invalid-argument', 'Restaurant ID is required' // or 'Item ID is required' );
Used by CRUD operations to fetch item details after create/update.

▶ getAllCategories INTERNAL Fetch categories ordered by order field
Function Signature
getAllCategories(restaurantRef: DocumentReference): Promise<Category[]> // Categories are ordered by 'order' field ascending // Throws error if any category is missing 'name' field // Returns: [{ id, name, order, description?, image? }]
Throws (Error)
// Thrown if any category document is missing the 'name' field throw new Error('Category name is missing');
⚠️ Critical validation: Categories MUST have a name field or the function throws.
▶ updateMenuItemStock INTERNAL Update isInStock field for a menu item
Function Signature
updateMenuItemStock( restaurantId: string, menuItemId: string, isInStock: boolean ): Promise<boolean> // Updates: { isInStock, lastUpdated: serverTimestamp() } // Throws Error('isInStock must be a boolean') if type check fails
Throws (Error)
// Thrown when isInStock is not a boolean type throw new Error('isInStock must be a boolean'); // Also validates via MenuValidation: throw new functions.https.HttpsError( 'invalid-argument', 'Restaurant ID is required' // or 'Item ID is required' );
Used by updateMenuItemAvailability HTTP endpoint. Also directly callable from other backend functions.
▶ getAllMenuItemsInStock INTERNAL Fetch only in-stock menu items
Function Signature
getAllMenuItemsInStock(restaurantId: string): Promise<MenuItem[]> // Uses Firestore query: where('isInStock', '==', true) // Returns only menu items with isInStock === true
▶ getFullMenu INTERNAL Fetch categories + menu items (non-organized)
Function Signature
getFullMenu(): Promise<{ categories: Category[], menuItems: MenuItem[] }> // Fetches categories and menu items in parallel via Promise.all // Note: menuItems is a flat array, NOT organized by category
▶ searchMenu INTERNAL Search menu items by name prefix
Function Signature
searchMenu(query: string): Promise<MenuItem[]> // Uses Firestore range query on meta.name field // where('meta.name', '>=', query) // where('meta.name', '<=', query + '\uf8ff')
Throws (Error)
// Thrown when query is empty or falsy throw new Error('Search query is required');
▶ getPopularItems INTERNAL Fetch most popular menu items
Function Signature
getPopularItems(limit: number = 10): Promise<MenuItem[]> // Assumes 'popularity' field exists on menu items // orderBy('popularity', 'desc').limit(limit)
⚠️ Requires a popularity field on menu item documents. May fail if field doesn't exist.

⚠️ Common Error Codes
Error Code HTTP Status Scenario
invalid-argument 400 Missing required fields, invalid field types, validation failures
not-found 404 Restaurant or MenuItem document doesn't exist
unauthenticated 401 Authentication required but missing (for protected endpoints)
permission-denied 403 User lacks permission for this operation
internal 500 Database errors, unexpected exceptions
Error Response Format
{ "status": "error", "code": "invalid-argument", // Error code "message": "Human-readable error message", "details": { // Optional - additional context "restaurantId": "...", "menuItemId": "...", "stage": "..." // Processing stage where error occurred } }
