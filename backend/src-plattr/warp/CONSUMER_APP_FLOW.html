🚩 Feature Flags (affect flow behavior)
🔑 isOtpMandatoryAtScan

When ON: OTP required at every QR scan
When OFF: Skip OTP if valid session exists

👤 isUsernameEnabled

When ON: Name field required during auth
When OFF: Only phone number needed

👥 isMultiUserSupportEnabled

When ON: Multiple users can join same table
When OFF: Only primary customer allowed

🔀 isMultipleVariantOrAddonSupported

When ON: Consolidate identical items in cart
When OFF: Each addition is separate entry

🎯 API Reference
Stage Function Key Parameters Notes
Entry validateTableAndLocation restaurantId, tableId, location, sessionId? Returns OTP requirement or grants access
Auth validateOTP restaurantId, tableId, otp, phoneNumber, name? Creates profile & session, returns token
Menu fetchMenu restaurantId, inStock? Returns categories + items + variants + addons
Cart addItemToCart menuItemId, variants, addons, qty, sessionId Validates stock & mandatory variants
Cart getCart restaurantId, tableId Auto-repairs missing data
Cart removeItemFromCart restaurantId, tableId, cartItemId Removes specific item
Cart clearCart restaurantId, tableId Clears entire cart
Checkout checkoutCart restaurantId, tableId, sessionId, notes? Re-validates stock/price, creates order
Order getOrder restaurantId, orderId?, tableId?, sessionId? Flexible retrieval options
Order updateCartStatus restaurantId, orderId, cartId, status Kitchen updates cart status
