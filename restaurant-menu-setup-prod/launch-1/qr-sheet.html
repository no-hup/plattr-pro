Table QR codes

Each code opens the ordering site for one table. Change the fields, then print (⌘P) — the settings bar is not printed. Print at 100% scale on A4; one code per card.

URL pattern: {site}/#/r/{restaurant}/t/{prefix}{n} (the # is REQUIRED — the consumer app uses hash routing; without it every scan lands on the dev restaurant picker and errors). Table numbers on the cards match {prefix}{n}.
