cart-fetchCart · Empty Cart

Graceful empty payload with zero totals instead of null cart references.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table002"
  }
}

Sample Response

{
  "status": "success",
  "message": "Cart fetched",
  "data": {
    "cart": {
      "tableId": "table002",
      "items": [],
      "priceSummary": {
        "subtotal": 0,
        "discountTotal": 0,
        "finalPrice": 0
      }
    }
  }
}
