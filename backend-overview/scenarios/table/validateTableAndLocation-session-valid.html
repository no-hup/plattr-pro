table-validateTableAndLocation

Scenario: Session OK – existing sessionId unlocks the menu immediately.

Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table001",
    "userLocation": { "latitude": 12.9716, "longitude": 77.5946 },
    "sessionId": "sess_active_a1"
  }
}

Response

{
  "status": "success",
  "message": "Session validated",
  "data": {
    "sessionId": "sess_active_a1",
    "expiresAt": "2025-11-14T10:13:00Z",
    "tableState": "ACTIVE",
    "requiresOtp": false
  }
}

Notes

  • Bypasses OTP when the sessionId is still valid and table is ACTIVE.
  • Downstream nodes: menu-fetchMenu (loads immediately).
