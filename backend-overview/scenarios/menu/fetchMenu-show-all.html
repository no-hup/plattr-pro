menu-fetchMenu

Scenario: Admin/debug toggle fetches entire menu regardless of stock.

Request

{
  "data": {
    "restaurantId": "rest001",
    "inStock": false
  }
}

Response

{
  "status": "success",
  "message": "Menu fetched",
  "data": {
    "categories": [ ... ],
    "menuItems": {
      "cat_burgers": [
        { "id": "item_classic_burger", "isInStock": true },
        { "id": "item_secret_patty", "isInStock": false }
      ],
      "cat_beverages": [
        { "id": "item_chai_latte", "isInStock": true }
      ]
    }
  }
}

Notes

  • Useful for staff experiences which show disabled dishes.
  • Clients should gray out isInStock=false items before enabling add-to-cart.
