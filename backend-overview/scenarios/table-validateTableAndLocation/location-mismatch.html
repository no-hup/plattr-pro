table-validateTableAndLocation · Location Mismatch

The reported GPS coordinates are outside the configured radius for the restaurant, so the callable throws a failed-precondition error.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table001",
    "userLocation": {
      "latitude": 13.0350,
      "longitude": 77.5970,
      "accuracy": 35.0
    }
  }
}

Sample Error Response

{
  "status": "error",
  "message": "User is outside the restaurant geofence",
  "error": {
    "code": "location-mismatch",
    "httpCode": 412,
    "details": {
      "distanceMeters": 820,
      "allowedRadiusMeters": 200
    }
  }
}
