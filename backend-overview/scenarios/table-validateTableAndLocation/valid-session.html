table-validateTableAndLocation · Existing Session

The guest scanned the QR code while a valid session already existed for the table. The function validates geolocation and immediately returns the session payload, skipping OTP.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table001",
    "userLocation": {
      "latitude": 12.9716,
      "longitude": 77.5946,
      "accuracy": 9.8
    },
    "sessionId": "session_abc123"
  }
}

Sample Response

{
  "status": "success",
  "message": "Active session found",
  "data": {
    "session": {
      "sessionId": "session_abc123",
      "expiresAt": "2024-01-01T14:00:00Z",
      "users": [
        {
          "customerId": "cust001",
          "isPrimary": true,
          "username": "John Doe"
        }
      ],
      "tableStatus": "ACTIVE"
    },
    "auth": {
      "requiresOtp": false
    }
  }
}
