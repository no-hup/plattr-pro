cart-addItemToCart · Quantity Increment

Identical configuration already exists, so the callable increments quantity and recalculates aggregate price totals.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table001",
    "menuItemId": "item001",
    "quantity": 2,
    "selectedVariants": {
      "variant_burger_size": "burger_size_large"
    },
    "selectedAddons": ["addon_burger_fries"],
    "sessionId": "session_abc123"
  }
}

Sample Response

{
  "status": "success",
  "message": "Cart updated",
  "data": {
    "cartItem": {
      "cartItemId": 7,
      "quantity": 3,
      "priceInfo": {
        "totalBasePrice": 420,
        "finalPrice": 378,
        "discount": 10
      }
    }
  }
}
