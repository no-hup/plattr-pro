cart-checkoutCart · New Order

Scenario: Creates a fresh order because no active order exists for the session.

Sample Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table009",
    "sessionId": "sess_table009_primary",
    "notes": "Less spicy"
  }
}

Sample Response

{
  "status": "success",
  "message": "Checkout completed successfully.",
  "data": {
    "orderId": "order_20251114_001",
    "orderNumber": "ORD-458",
    "orderStatus": "active",
    "timestamp": "2025-11-14T10:18:22Z"
  }
}

Notes

  • Clears the cart document upon success.
  • Emits FCM notifications when sendServerNotifications flag is true.
