cart-checkoutCart

Scenario: Adds items to an active order (same session still seated).

Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table009",
    "sessionId": "sess_table009_primary",
    "notes": "Dessert round",
    "expectedTotal": 312,
    "appendToActiveOrder": true
  }
}

Response

{
  "status": "success",
  "message": "Items appended",
  "data": {
    "orderId": "order_20251114_001",
    "orderStatus": "active",
    "addedCartId": "cart_table009_2025_11_14_round2",
    "timestamp": "2025-11-14T10:34:02Z"
  }
}

Notes

  • Uses existing order document and creates an additional cart entry inside orders/{orderId}.carts.
  • Kitchen notifications only reference the new cart payload.
