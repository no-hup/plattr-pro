cart-addItemToCart

Scenario: Identical configuration already exists; quantity increments instead of creating a new row.

Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table009",
    "menuItemId": "item_classic_burger",
    "quantity": 2,
    "selectedVariants": { "variant_size": "large" },
    "selectedAddons": ["addon_fries"],
    "sessionId": "sess_table009_primary"
  }
}

Response

{
  "status": "success",
  "message": "Quantity updated",
  "data": {
    "cartItemId": 7,
    "quantity": 3,
    "merge": true,
    "priceInfo": {
      "finalPrice": 594,
      "totalDiscountAmount": 66
    }
  }
}

Notes

  • Matching logic compares menu item + variant + addons arrays.
  • Enables consistent UI behavior during optimistic updates.
