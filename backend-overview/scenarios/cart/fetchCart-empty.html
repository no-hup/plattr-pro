cart-fetchCart

Scenario: Table cart exists but contains zero items after cleanup.

Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table010"
  }
}

Response

{
  "status": "success",
  "message": "Cart fetched",
  "data": {
    "items": [],
    "priceSummary": {
      "subtotal": 0,
      "discount": 0,
      "finalPrice": 0
    }
  }
}

Notes

  • Ensures the frontend never receives null carts.
  • Cart document stays around for auditability until TTL clears it.
