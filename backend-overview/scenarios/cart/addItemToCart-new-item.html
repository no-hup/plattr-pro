cart-addItemToCart

Scenario: Customer adds a brand-new configuration to the cart.

Request

{
  "data": {
    "restaurantId": "rest001",
    "tableId": "table009",
    "menuItemId": "item_classic_burger",
    "quantity": 1,
    "selectedVariants": { "variant_size": "large" },
    "selectedAddons": ["addon_fries"],
    "sessionId": "sess_table009_primary"
  }
}

Response

{
  "status": "success",
  "message": "Item added to cart",
  "data": {
    "cartItemId": 7,
    "priceInfo": {
      "itemBasePrice": 180,
      "totalAddonBasePrice": 40,
      "discount": 10,
      "finalPrice": 198
    },
    "quantity": 1,
    "merge": false
  }
}

Notes

  • Triggers downstream cart enrichment when cart-fetchCart runs.
  • All price math is server-side using the same helpers as checkout.
